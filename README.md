# Neon Tape

Кассетный лофи-плеер для фокус-смены на 8 часов. Музыка генерируется в браузере (Web Audio API), аудиофайлов нет.

## Запуск локально
Service worker работает только по https или на localhost:

    npx serve .        # или: python3 -m http.server 8080

## Деплой на GitHub Pages
1. Создай репозиторий `neon-tape`, залей содержимое этой папки в корень.
2. Settings → Pages → Source: Deploy from a branch → `main` / root.
3. Через минуту открой `https://<логин>.github.io/neon-tape/`.
4. Телефон: Safari → «Поделиться» → «На экран Домой». Android/Chrome: меню → «Установить приложение».

## Обновление
После правок меняй `VERSION` в `sw.js`, иначе браузер отдаст старый кэш.

## Логика
- Блок фокуса 50 мин → напоминание о перерыве 10 мин, каждый 4-й перерыв 20 мин.
- Пауза дольше 5 мин засчитывается как перерыв, короче — как «короткая пауза».
- 3+ короткие паузы за блок → подсказка взять нормальный перерыв.
- Прогресс смены хранится в localStorage (`neon-tape-v1`), сбрасывается на следующий день.
